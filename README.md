# OptiQueue — Smart Hospital Queue Management System

Software-only hospital queue management project.

## Project modules
- `Patient-App/` — Expo / React Native patient application
- `Admin-Panel/` — Expo web/admin interface
- `Live-Queue/` — Expo live waiting-room display
- `Backend/` — Express REST API
- `Database/` — Supabase PostgreSQL 

## Important project status
The supplied frontend folders are preserved from the original project ZIP. Their screens include demo/static data. The backend API and database setup are included in this package, but frontend-to-backend API integration, end-to-end testing, and production deployment are still required. Do not present the system as production-ready until those steps are completed.
